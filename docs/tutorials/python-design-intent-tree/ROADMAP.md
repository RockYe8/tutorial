# Python 设计意图树 24 章路线图

这份路线图限定课程边界：只专注 Python 语言本身，以及为了让 Python 不再成为工程化、学术化障碍所必需的项目运行边界。外部框架、机器学习库、Web 框架、大模型工程和论文领域知识不进入主线；它们以后可以作为应用场景回到这些语言机制上理解。

每章采用同一工作方式：先形成完整 `## 本章推理总览`，经审阅确认后再展开正文。正文只展开总览中已经成立的逻辑链；正文完成后安排最小练习和反馈问题；学习记录只在练习完成并表现出理解后写入。

## 第一部分：运行、对象、名字和结构

1. [运行模型：源码如何变成对象、名字、命名空间和模块](01-running-model-code-blocks-namespaces.md)
2. [数据结构：`list`、`tuple`、`dict`、`set` 如何组织对象引用](02-data-structures-object-organization.md)
3. [函数：`def`、参数、返回值、局部命名空间和行为复用](03-functions-behavior-objects.md)
4. [模块和包：`import`、package、模块对象、导入缓存和边界](04-modules-packages-import-boundaries.md)
5. [可读结构：缩进、suite、命名约定、docstring、future 和格式边界](05-readable-code-visible-structure-conventions.md)

这一部分建立 Python 程序最基本的判断：代码如何运行，运行后形成什么对象，名字如何找到对象，多个对象如何被组织，行为如何被抽出，多个文件如何形成边界，以及代码变长后哪些结构由语言强制、哪些结构由协作约定稳定。

## 第二部分：失败、状态和对象边界

6. 错误与资源边界：`exception`、`try`、`except`、`raise`、`finally`、`with`
7. 类和实例：`class`、instance、attribute、method、`self`
8. 属性查找：实例属性、类属性、方法绑定和查找顺序
9. 可变状态：对象状态、别名、副作用、拷贝和共享引用
10. 继承与组合：继承、组合、替换关系和边界代价
11. Python 数据模型：特殊方法、协议、`len`、`iter`、`in`、上下文管理

这一部分处理真实程序最容易变复杂的地方：失败如何传播，资源如何清理，状态如何被修改和共享，数据与行为何时应该合到对象里，属性访问为什么不是简单字典查找，继承何时制造扩展点、何时制造耦合，以及 Python 如何用协议让对象参与内置语法和函数。

## 第三部分：控制流、迭代和表达力

12. 迭代模型：iterable、iterator、`for`、`range`、`enumerate`
13. 生成器：`yield`、惰性计算、流式数据和一次性迭代
14. 推导式：list/dict/set comprehension、generator expression
15. 作用域深入：`global`、`nonlocal`、closure、late binding
16. 装饰器：函数包装、语法糖、横切逻辑和边界代价

这一部分让 Python 的表达力变得可控。工程代码和学术代码常常用迭代表达批处理，用生成器表达惰性数据流，用推导式压缩局部转换，用闭包保存环境，用装饰器包裹横切行为。课程只解释这些语言机制的边界和代价，不把它们变成炫技语法。

## 第四部分：契约、项目和可验证性

17. 类型注解：annotation、`typing`、可选值、联合类型和工具边界
18. 数据承载形式：`dataclass`、`NamedTuple`、`Enum` 和不可变意图
19. 文件与序列化：`pathlib`、`open`、文本/字节、JSON、pickle 边界
20. 标准库组合工具：`collections`、`itertools`、`functools`、`contextlib`
21. 环境与依赖：`venv`、`pip`、`pyproject.toml`、版本和可复现运行
22. 测试反馈：`assert`、测试函数、fixture 思想和可测试边界
23. 调试、日志和配置：traceback、`logging`、环境变量和配置边界
24. 综合阅读：如何阅读一个中型 Python 项目的语言结构

这一部分把语言机制放进可维护项目里。类型注解帮助读者和工具理解边界，数据承载形式减少样板和歧义，文件与序列化让数据进出程序，标准库组合工具提供稳定抽象，环境与依赖让代码可复现运行，测试、日志和配置让程序能被验证、诊断和调整。最后一章把前面机制合起来，用一套阅读方法拆解中型 Python 项目的结构。

## 路线边界

这套课程会使用工程和学术场景作为例子，但不把例子扩展成框架课。

- 可以用“读取实验配置文件”解释路径、文本、JSON 和异常；不展开实验管理平台。
- 可以用“处理一批样本”解释迭代器、生成器和测试；不展开数据科学框架。
- 可以用“项目依赖无法复现”解释虚拟环境和包版本；不展开发布到 PyPI 的完整流程。
- 可以用“阅读论文代码仓库”解释模块、对象、配置和入口；不展开具体论文算法。

完成 24 章后，Python 不再只是能写脚本的工具，而会成为可用于工程项目、学术代码阅读、实验复现和后续应用学习的稳定语言底座。
